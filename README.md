# MATSANDA HUB
### Matsanda Digital Gateway
The official portal website for MTs Negeri 2 Kota Semarang, providing access to a variety of information, services, and resources through a single, convenient, and easily accessible portal page.

## File Structure
- `Matsanda Hub` - Main Branch
- `├ assets/` - Assets Folder
- `│ ├ matsanda_hub-icon.png` - Website Icon
- `│ └ matsanda_hub-meta-banner.png` - Meta Banner
- `├ index.html` - Main Page
- `├ style.css` - Page Style CSS
- `└ script.js` - Page Script
